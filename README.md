# AI Job Match Dashboard

An AI-powered dashboard that helps job seekers identify the best opportunities by comparing job postings with their resume.

## Planned Features

- Collect jobs from company career pages
- Store jobs in a database
- AI-powered match scoring
- Resume analysis
- Resume and cover letter generation
- Application tracking
- Analytics dashboard

## Tech Stack

- Python
- Streamlit
- PostgreSQL
- SQLAlchemy
- OpenAI API
- Docker
